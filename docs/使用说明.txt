桌面弹簧玩偶（Windows 10 / 11）

双击“桌面弹簧玩偶.exe”即可运行。四个角色会出现在屏幕下方。
素材已嵌入程序，复制这一个 exe 文件到其他文件夹也可以运行。
使用 Windows 自带的 .NET Framework 4.x，无需安装 Python 或 Node.js。

操作：
  单击角色：头部像弹簧玩偶一样来回摇动，逐渐停下。
  右键“说话：国模完蛋了”：显示这句话的文字气泡，4 秒后消失。
  勾选“点击时显示气泡”：之后单击角色时也显示这句话。默认关闭。
  按住鼠标左键拖动：移动这个角色。
  右键角色：摇头、四个一起摇、放大、缩小、置顶、恢复位置、隐藏、退出。
  屏幕右下角托盘图标：显示/隐藏全部角色、恢复位置、退出。
  双击托盘图标：四个一起摇。

位置和大小会自动保存。透明区域可操作后面的窗口。
“说话”仅为文字气泡，不播放声音。气泡不会拦截鼠标操作。
颈部已去除重复的素材接头，左右摇动时保持连接。
没有开机自启；需要时双击启动即可。
退出请右键角色或托盘图标，选择“退出全部玩偶”。

设置文件：%LOCALAPPDATA%\FourBobbleheads\settings.xml
“恢复默认位置和大小”可以找回移出屏幕的角色。

素材说明：参照用户提供的四人插图，由内置 imagegen 整理为透明头部与身体。
部分绘制细节与原图略有差异，属于二维桌面玩偶。
